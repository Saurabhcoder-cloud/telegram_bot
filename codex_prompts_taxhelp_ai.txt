PROMPT 1 — Project Initialization
Create a full-stack web project named TaxHelp AI that helps U.S. users file taxes using AI and OCR. Use:

* Frontend: Next.js (React) + TailwindCSS
* Backend: Node.js + Express
* Database: PostgreSQL
  The project must include folders: /frontend, /backend, /database. Generate package.json files for frontend and backend and a root README.md describing the project.

PROMPT 2 — Authentication Module
In the backend, create user authentication with email/password and Google OAuth. Use JWT tokens. Create SQL table:
users(id SERIAL PRIMARY KEY, name VARCHAR, email VARCHAR UNIQUE, password VARCHAR, plan VARCHAR, plan_expiry DATE)
APIs:

* POST /auth/register
* POST /auth/login
* GET /auth/user/:id
  Return example responses and error handling. Include password hashing and token expiry.

PROMPT 3 — AI Chat Assistant
Create a backend API /chat/ask that:

* Accepts { user_id, question, language }
* Performs a RAG lookup against an IRS knowledge base (PDFs/web pages) to retrieve supporting passages
* Calls OpenAI (GPT) to generate an answer that cites the retrieved passages
* Translates the final answer into the user's language using Google Translate API, if language != 'en'
  Return JSON: { answer, citations: [{title, url}], language }
  Also generate frontend React chat UI (message bubbles, timestamps, typing indicator) that posts to /chat/ask.

PROMPT 4 — Subscription Plans (3 Paid Plans)
Add 3 plans in pricing page and API: Standard ($9.00/month), Pro ($19.00/month), Premium ($29.00/month).
Frontend: pricing table + "Buy Now" button for each plan.
Backend: POST /api/payment/create-checkout-session that creates a Stripe Checkout Session with metadata { user_id, plan } and returns the session URL.
Provide webhook handler /api/payment/webhook that verifies Stripe signature, reads checkout.session.completed, and updates user's plan and expiry in DB. Save transaction record.

---

PROMPT 5 — Tax Filing (OCR + Mapping + PDF)
Create API /api/tax/file that accepts multipart/form-data file uploads (W-2, 1099). Steps:

* Store file temporarily (S3 or local)
* Send to Google Vision API or AWS Textract for OCR
* Extract key fields and map to Form 1040 JSON schema (use mapping rules)
* Call tax calculation (/api/tax/calculate) to compute tax_due/refund
* Generate populated PDF (Form 1040 + required schedules) and return a secure download URL
  Include example mapping table and error handling for unreadable uploads.

PROMPT 6 — Stripe Payment Flow
Implement Stripe integration details:

* plans object: { standard: 9.00, pro: 19.00, premium: 29.00 }
* POST /api/payment/create-checkout-session: create session with metadata user_id & plan
* POST /api/payment/webhook: on checkout.session.completed, update payments table and user.plan & plan_expiry
  Provide SQL for payments table and a sample webhook verification snippet.

PROMPT 7 — Refund Calculator
Create frontend route /refund-calculator and backend POST /api/tax/calculate that accepts { filing_status, dependents, annual_income, federal_withheld, deductions (optional) } and returns { taxable_income, tax_due, refund, status }.
Implement IRS 2024 tax brackets for Single/Married/Head of Household and default standard deductions. Include child tax credit logic ($2,000 per qualifying child) in calculation.
